一、什么是梅林小宝？它为何如此受欢迎？

“梅林小宝”并非一个独立的软件，而是一款基于**华硕梅林固件（Asuswrt-Merlin）**开发的插件级科学上网管理工具，通常以“脚本+Web前端”的形式存在。它的核心价值，在于将科学上网功能集成到路由器层面，从根本上解决多设备、多终端接入的问题。

为什么选择梅林小宝？

  • 全局代理能力强：部署在路由器层，可为全家所有设备（手机、电视、平板、游戏机）提供稳定代理。

  • 界面友好、操作简单：相比手动配置代理或iptables，梅林小宝提供了简洁直观的可视化操作界面。

  • 插件管理方便：支持在线升级、配置导入导出、定时更新规则等自动化功能。

  • 规则分流灵活：支持GFW列表、国内外域名自动识别分流，有效提高访问效率。

  • 免费开源、社区活跃：有强大的开发者社区支持，教程丰富，问题解决迅速。

二、使用梅林小宝前的准备工作

你需要具备：

  1. 一台支持梅林固件的华硕或刷了梅林固件的路由器
    常见支持机型包括：华硕AC86U、AC68U、AX86U、AX88U、GT-AC2900等。

  2. 可以访问互联网的电脑或手机
    用于下载插件文件、访问管理后台、输入配置信息等。

  3. 一个可用的科学上网节点（代理服务器）
    可为VMess、VLess、Trojan、Shadowsocks等，需提前准备好地址、端口、UUID/密码等信息。

  4. 基础的路由器操作知识
    了解如何进入路由器管理后台、刷固件、安装插件等操作更佳。

三、安装步骤详解：从固件到插件全面部署

Step 1：刷入梅林固件

如果你的路由器尚未安装梅林固件，需要先进行刷机操作：

  1. 访问华硕梅林固件官网或Koolshare论坛；

  2. 下载与你机型对应的固件版本（注意选择稳定版）；

  3. 登录路由器后台（通常是192.168.50.1），进入**“系统管理 > 固件升级”**；

  4. 上传下载的固件文件，等待重启完成；

  5. 成功后界面左下角会显示“Merlin”字样，表明固件已正确安装。

⚠️ 刷机风险需谨慎，操作前务必备份配置，并确保电源稳定。

Step 2：安装Entware环境（插件运行基础）

  1. 登录梅林后台，进入**“软件中心”**；

  2. 安装Entware环境支持（首次使用时系统会自动提示）；

  3. 系统会挂载USB或内部存储空间作为插件依赖目录。

Step 3：安装梅林小宝插件

目前较流行的版本为Koolshare出品的科学上网插件（原梅林小宝），安装方式如下：

  1. 前往Koolshare或GitHub相关页面下载.ipk插件安装包；

  2. 登录路由器后台 → 进入“软件中心” → 选择“手动上传插件”；

  3. 选择刚下载的安装包，点击上传并安装；

  4. 安装完成后，系统将自动在“软件中心”显示科学上网插件（小飞机图标）；

  5. 点击进入插件，即可开始配置。

四、详细配置教程：让你的网络飞起来

1. 添加代理服务器节点

进入梅林小宝界面后，按照以下方式添加代理服务器：

  • 选择**“节点管理”**；

  • 点击“添加节点”；

  • 填入服务器信息（节点名、地址、端口、UUID或密码、协议类型）；

  • 可手动测试连通性并保存。

支持协议包括：

  • Shadowsocks（SS）

  • ShadowsocksR（SSR）

  • V2Ray（VMess/VLess）

  • Trojan（TLS）

2. 设置DNS加速与污染防护

科学上网中DNS设置同样关键：

  • 启用DNS防污染功能；

  • 推荐使用DoH/DoT协议的公共DNS（如Cloudflare 1.1.1.1、Google 8.8.8.8）；

  • 可开启SmartDNS插件，提升域名解析速度并实现自动分流。

3. 配置分流规则

在“访问控制”与“国外网站走代理”栏目中，你可以自由选择：

  • GFW模式：仅代理被墙网站，国内流量直连；

  • 绕过大陆IP模式：所有非中国大陆IP走代理；

  • 全局模式：所有流量均通过代理（适合测试或紧急情况下使用）；

  • 自定义ACL规则：按设备、端口、IP自定义走代理或直连。

4. 启动服务并测试连接

一切设置就绪后：

  1. 返回主界面；

  2. 点击“启动科学上网”；

  3. 页面将显示运行状态、当前流量、DNS状态等实时数据；

  4. 使用手机或电脑访问Google、YouTube等网站测试连接是否成功。

若出现连接失败，请检查网络、节点可用性、DNS设置是否冲突等问题。

五、常见问题与解决方案（FAQ）

Q1：为何配置后无法访问外网？

  • 检查代理服务器参数是否正确；

  • 是否忘记启动插件服务；

  • DNS未配置或被污染导致域名无法解析。

Q2：如何实现按设备分流？

在“访问控制”中添加MAC地址或IP地址，实现精细化管理。

例如：电视全局代理，电脑走GFW模式，打印机则完全直连。

Q3：如何自动更新规则？

插件支持定时自动更新GFW列表与路由表，建议每天更新一次，保障流畅性与有效性。

Q4：梅林小宝插件是否收费？

插件本身为开源免费项目，使用过程中无需额外费用。但代理节点（机场）多数为付费服务。

FAQ

Surfboard 可以导入哪些格式的规则文件？
Surfboard 支持 YAML 和部分 JSON 格式的规则文件，用户可以导入节点、策略组和分流规则。注意文件格式和语法必须符合 Surfboard 规范，否则可能导入失败。
Clash 是否支持 DNS 分流？
支持。Clash 可以自定义 DNS 服务器，并通过 rules 区分国内外域名解析方式。比如国内网站可使用本地 DNS，国外网站可走代理 DNS，从而提升访问速度与稳定性。
Matsuri 的多节点测速机制是怎样的？
Matsuri 使用并发测速机制，可同时对多个节点进行延迟与带宽测试。测试结果会自动排序，并可根据延迟或速度自动切换最优节点，提升连接体验。
PassWall2 如何结合延迟选择最优节点？
PassWall2 定期测速节点延迟，并结合策略组自动选择延迟最低的节点。无需手动操作即可保证网页、视频和游戏流量快速稳定访问，提高整体网络体验。
V2Ray 中的多入口（inbounds）配置有什么用？
V2Ray 支持多入口配置，可以同时开启 HTTP、Socks、TUN 等多种代理方式，方便不同程序接入。通过设置不同端口，用户可实现局域网共享或分离不同流量来源。
Sing-box 的多策略组能带来什么优势？
多策略组可将节点按用途或地域分类，结合路由规则实现精准分流。用户无需频繁切换节点即可自动使用最佳线路，提高网络访问效率和稳定性。
Clash 的节点健康检测如何工作？
Clash 会定期对每个节点进行延迟和丢包率测试，并根据结果标记节点健康状态。结合策略组，可以自动切换到最优节点，避免访问高延迟或失效节点，提高整体网络稳定性和效率。
Trojan 的证书配置错误会导致什么问题？
如果 TLS 证书无效或域名不匹配，Trojan 客户端将无法建立安全连接，导致节点无法使用。需要确保证书有效、域名正确，才能保证正常访问。
Potatso Lite 能否手动添加节点？
Potatso Lite 支持手动添加 Shadowsocks 节点。用户在“配置”中选择添加节点，输入服务器、端口、加密方式等信息即可建立连接，适合手动管理单个线路。
Trojan-Go 的端口不可达怎么办？
检查服务器防火墙是否开放对应端口，同时确认客户端和服务器端端口一致。还可以尝试更换节点或端口，确保 TLS 证书有效以保证连接成功。
